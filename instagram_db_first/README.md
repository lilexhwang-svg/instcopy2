# Instagram DB Project

## 저장한 게시물·좋아요한 게시물·내 프로필의 서버 오류 수정

이전 DB에 `likes.created_at`, `saved_posts.created_at`, `users.bio`,
`users.avatar_path`가 빠져 있으면 해당 화면에서 서버 오류가 발생합니다.
이제 서버 시작 시 기존 테이블과 필요한 컬럼을 자동으로 보완합니다.
`run.bat`과 `uvicorn app:app` 모두에 적용되며 기존 회원·게시물·좋아요·저장은 보존합니다.

수정 후에는 실행 중인 서버 창을 닫고 상위 폴더의 `run.bat`을 더블클릭한 뒤
브라우저를 새로고침하세요. DB 설정은 앱 폴더의 `.env`에서 읽습니다.

MySQL을 중심으로 구현한 인스타그램 형태의 사진 공유 웹 서비스입니다.  
데이터베이스 수업 텀프로젝트로, 테이블 간 관계와 SQL을 활용해 주요 기능을 구현했습니다.

## 기술 스택

- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, Jinja2
- **Database:** MySQL

## 주요 기능

- 회원가입, 로그인, 비밀번호 변경
- 사용자 팔로우 및 팔로워·팔로잉 목록 조회
- 사진과 설명을 포함한 게시물 작성
- 댓글 작성 및 `@아이디` 멘션
- 내 게시물과 팔로우한 사용자의 게시물을 최신순으로 보여주는 홈 피드
- 사용자 프로필 및 게시물 조회

## 데이터베이스 구성

| 테이블 | 역할 |
| --- | --- |
| `users` | 회원·프로필 정보 |
| `posts` | 게시물 및 이미지 경로 |
| `comments` | 게시물 댓글 |
| `follows` | 사용자 간 팔로우 관계 |
| `likes` | 게시물 좋아요 |
| `saved_posts` | 개인별 게시물 저장 |
| `hashtags` | 해시태그 정보 |
| `post_hashtags` | 게시물과 해시태그 연결 |
| `comment_likes` | 댓글 좋아요 |

기본키(PK), 외래키(FK), 복합키, CHECK 제약조건과 `ON DELETE CASCADE`를 적용했습니다.
회원·게시물·댓글·팔로우 등의 데이터는 MySQL에 저장하고, 이미지 파일은 별도로 저장합니다.
